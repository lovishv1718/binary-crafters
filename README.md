# Binary Crafters website

Agency website for Binary Crafters (Vancouver), built with **Next.js** and **Payload CMS**.
The public site and the admin panel live in the same app.

- Website: `http://localhost:3000`
- Admin panel: `http://localhost:3000/admin`

## Run it locally

```bash
npm install
npm run dev
```

First time only, fill the empty database with demo content (services, results, blog posts, testimonials):

```bash
npm run seed
```

The seed also creates a local admin login from `SEED_ADMIN_EMAIL` / `SEED_ADMIN_PASSWORD` in `.env`.
It never overwrites existing content: it stops if services already exist.

## What the client can edit in /admin

| Section | What it controls |
| --- | --- |
| **Blog posts** | Write, save drafts, schedule and publish articles with images. Categories filter the blog. |
| **Results** | Client wins: cover image, unlimited proof screenshots (gallery), key numbers, story, quote. Tag a result with services and it appears on those service pages automatically. Tick *Featured* to show it on the home page. |
| **Services** | Title, card text, page heading, cover image, deliverables, process steps and FAQs. |
| **Testimonials** | Quotes shown on the home page. |
| **Media** | Every uploaded image. Set a focal point so crops look right. |
| **Enquiries** | Messages from the contact form, with a status (New, Contacted, Won, Not a fit). |
| **Site settings** | Phone, email, location, hours, social links, the home page headline and stats, and the hero / about photos. |

The hero and "Who we are" photos default to free Unsplash stock images (`src/lib/photos.ts`).
Upload real team or office photos in Site settings → Home page to replace them.

## Hosting (Vercel)

Live at https://binary-crafters.vercel.app (Vercel project `binary-crafters`).

- Database: Neon Postgres (`DATABASE_URL`), images: Vercel Blob (`BLOB_READ_WRITE_TOKEN`), both set in Vercel.
- Local development keeps using SQLite and the `media/` folder; `.env.deploy` (never commit) holds the hosted values.
- Deploy code changes: `vercel deploy --prod`
- After changing a collection's fields, create a migration against Neon before deploying:
  `set -a; . ./.env.deploy; set +a; npx payload migrate:create <name>` — it runs automatically on the next deploy.

## Before going live

1. **Replace the demo content.** All results, testimonials, stats and client names from the seed are placeholders.
   The images are generated mockups. Swap in real screenshots and real numbers, or delete them.
2. **Change the admin password** (or create the real admin and delete the local one).
3. **Production database and file storage.** SQLite and the local `media/` folder are for development.
   For hosting on Vercel, switch to Postgres (`@payloadcms/db-postgres`, for example Neon) and a storage
   adapter for uploads (`@payloadcms/storage-vercel-blob` or S3). A VPS can keep SQLite and `media/`.
4. Set `PAYLOAD_SECRET` to a long random string and `NEXT_PUBLIC_SITE_URL` to the real domain.
5. Optional: add an email adapter so new enquiries are emailed to info@binarycrafters.com.

## Project layout

```
src/
  app/(frontend)/     public website pages and styles.css (design system)
  app/(payload)/      admin panel (generated by Payload)
  collections/        CMS content types
  globals/            Site settings
  components/         shared UI (header, footer, cards, icons)
  seed/               demo content and generated placeholder images
public/brand/         logo files (mark.png for dark backgrounds, mark-dark.png for light)
```
